# 杭州旅游攻略网页

[中文](README.md) | [English](README_EN.md)

## 项目简介

这是一个精美的杭州五一旅游攻略网页，为游客提供杭州旅游的全方位信息，包括行程安排、景点介绍、美食推荐、住宿建议以及实用的旅行小贴士。

## 特色功能

- **精心设计的视觉界面**：采用杭州西湖特色的配色方案，搭配精美图标
- **详细的行程规划**：根据天气情况安排的四天行程
- **景点详情**：包含西湖、雷峰塔、灵隐寺等杭州著名景点的详细介绍
- **美食推荐**：介绍西湖醋鱼、东坡肉等杭州特色美食
- **住宿建议**：提供西湖周边和市中心的住宿选择
- **旅行小贴士**：实用的旅行建议，帮助游客更好地规划行程

## 技术特点

- **响应式设计**：适配不同屏幕尺寸的设备
- **现代CSS技术**：
  - CSS变量实现主题配色
  - Flexbox布局
  - 渐变色背景
  - 悬停动画效果
- **Font Awesome图标**：使用丰富的图标增强视觉体验
- **优化的视觉层次**：通过色彩、阴影和间距创建清晰的信息层次

## 页面结构

- **页眉**：网页标题和简介
- **天气预报**：五一期间杭州天气情况
- **行程安排**：四天详细行程
- **景点详情**：主要景点介绍
- **美食推荐**：杭州特色美食
- **住宿建议**：酒店推荐
- **旅行小贴士**：实用建议
- **页脚**：版权信息

## 如何使用

1. 克隆或下载本项目
2. 在浏览器中打开`index.html`文件
3. 浏览杭州旅游攻略内容

## 设计亮点

- **西湖蓝色调**：主色调采用西湖蓝色，呈现杭州水乡特色
- **图标丰富**：每个景点和功能区域都配有相应的图标
- **卡片式设计**：信息以卡片形式呈现，清晰直观
- **互动效果**：添加了悬停动画，增强用户体验
- **层次分明**：通过色彩和间距区分不同类型的信息
