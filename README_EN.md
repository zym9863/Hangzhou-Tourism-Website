# Hangzhou Tourism Website

[中文](README.md) | [English](README_EN.md)

## Project Introduction

This is an elegant Hangzhou May Day holiday travel guide website, providing comprehensive information for tourists visiting Hangzhou, including itinerary arrangements, attraction introductions, food recommendations, accommodation suggestions, and practical travel tips.

## Features

- **Carefully Designed Visual Interface**: Using Hangzhou West Lake's characteristic color scheme, paired with beautiful icons
- **Detailed Itinerary Planning**: Four-day itinerary arranged according to weather conditions
- **Attraction Details**: Detailed introductions to famous Hangzhou attractions including West Lake, Leifeng Pagoda, Lingyin Temple, etc.
- **Food Recommendations**: Introduction to Hangzhou specialties such as West Lake Fish in Vinegar Sauce, Dongpo Pork, etc.
- **Accommodation Suggestions**: Providing accommodation options around West Lake and in the city center
- **Travel Tips**: Practical travel advice to help tourists better plan their trip

## Technical Features

- **Responsive Design**: Adapts to devices with different screen sizes
- **Modern CSS Techniques**:
  - CSS variables for theme coloring
  - Flexbox layout
  - Gradient backgrounds
  - Hover animation effects
- **Font Awesome Icons**: Using rich icons to enhance visual experience
- **Optimized Visual Hierarchy**: Creating clear information hierarchy through colors, shadows, and spacing

## Page Structure

- **Header**: Website title and introduction
- **Weather Forecast**: Hangzhou weather conditions during the May Day holiday
- **Itinerary Arrangement**: Four-day detailed itinerary
- **Attraction Details**: Introduction to main attractions
- **Food Recommendations**: Hangzhou specialty foods
- **Accommodation Suggestions**: Hotel recommendations
- **Travel Tips**: Practical advice
- **Footer**: Copyright information

## How to Use

1. Clone or download this project
2. Open the `index.html` file in a browser
3. Browse the Hangzhou travel guide content

## Design Highlights

- **West Lake Blue Tone**: Main color scheme uses West Lake blue, presenting Hangzhou's water town characteristics
- **Rich Icons**: Each attraction and functional area is equipped with corresponding icons
- **Card Design**: Information presented in card form, clear and intuitive
- **Interactive Effects**: Added hover animations to enhance user experience
- **Clear Hierarchy**: Distinguishing different types of information through colors and spacing
